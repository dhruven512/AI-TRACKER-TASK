# 🚀 AI Task Tracker

A modern and responsive task management application built using React and Tailwind CSS. This app helps users efficiently manage daily tasks with a clean UI and smooth user experience.

---

## ✨ Features

- ✅ Add, delete, and manage tasks
- 🌙 Dark / Light mode toggle
- 💾 Local Storage (data persists after refresh)
- 🔍 Search and filter tasks
- ⚡ Fast and responsive UI
- ⌨️ Keyboard-friendly UX (Enter / Escape support)

---

## 🛠️ Tech Stack

- ⚛️ React.js
- 🎨 Tailwind CSS
- 🧠 JavaScript (ES6+)
